# Git Demo
An introductory working tree.

## Getting started
1. Download and install Git. The specific instructions depend on your operating system:
	- **Linux:** if it's not already pre-installed for your distro, you can most likely find Git in the package manager of your choosing.
	- **MacOS:** Either install Apple's Xcode command-line tools (`xcode-slect --install`) or use a package manager of your choosing (i.e. `brew install git`).
	- **Windows:** Either use winget (`winget install --id Git.Git -e --source winget`) or download the latest installer [here](https://git-scm.com/install/windows).
2. Initialize the git repository using `git init` in this directory.
3. Stage and commit the files using `git add --all` and `git commit -m "Initial commit"`.
4. You're done :)

## Making changes
1. Edit some files
2. `git add <path>`
3. `git commit -m "<description>"`
